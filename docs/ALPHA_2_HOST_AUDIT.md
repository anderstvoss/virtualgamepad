# Alpha 2 host setup and permissions audit

**Draft for C9 and Anders's sign-off.** This is the C8 inventory for the six C7
families. C9 must add Xbox Series surfaces before the Alpha 2 release gate
closes. Defaults below are proposed dispositions for review. The applications,
runner and library use already-provisioned access. This audit does not install
or enable host policy. [#258](https://github.com/anderstvoss/virtualgamepad/issues/258) ·
[Owner decision E2](https://github.com/anderstvoss/virtualgamepad/issues/322#issuecomment-6747067225)

Check the creating user's permissions separately from each consumer's. Use
`python3 scripts/host-preflight.py <realization-id>` for read-only inventory
and match the current association before opening or granting access to a child
node. Kernel names and path numbers can be reused. `uaccess` behavior depends
on the installed distribution policy and active seat.
