# Audio loss accounting (Brief 16 A0)

Status: source-level inventory and synthetic-only receipt. **No kalux host run, real PipeWire graph, USB/VHCI host or physical controller was exercised.** This is an A0 instrumenting PR, not closure of #143/#145 or a claim of 60-second continuity / latency.

The selected realization defines the host presentation, not what the application owns. The existing IDs are **unchanged**: Native HID `linux.uhid.usb` with `audio-pipewire` provides independent PipeWire sidecars; Real USB `linux.usbip.usb-audio` with `audio-usbip` provides emulated composite HID/UAC2 through the existing worker and root broker. `AudioAccess::Samples` and `AudioAccess::NativeClient` can be chosen independently per direction. The former is an application queue; the latter adds caller-side PipeWire graph/bridge. Neither asserts consumer auto-association or real-device acoustic behavior. See [controller audio](CONTROLLER_AUDIO.md), [Brief 16](plans/pre-controller-buildout/16-audio-haptics-buildout.md), and [ADR-0023](adr/ADR-0023-controller-subsystems.md).

## Inventory by direction, presentation and observation boundary

`H→C` means host playback / haptic PCM to the emulated controller. `C→H` means emulated controller microphone to the host. One frame means one synchronized interleaved channel set, not one `i16`. An **unaccepted partial write** remains caller-owned and is *not* loss until the caller abandons it. A queue `discard()`, a graph `EMPTY` event and a USB worker counter may describe overlapping frames: never add counters from different stages without a shared range/marker identity.

## Typed accounting contract

`ControllerAudio::diagnostics()` still returns the preexisting `AudioDiagnostics`: `is_closed()`, `failed()`, `underrun_frames()`, `dropped_playback_frames()` and `last_error()` are unchanged. Two **additive** optional getters `playback_accounting()` and `microphone_accounting()` return `AudioDirectionAccounting`, with direction, monotonic queue **generation** (starts at 1, increments on an explicit queue flush/reset; overflow fails rather than wrapping), produced/accepted/consumed frames, ingress discard, flush discard, outstanding terminal tail, queued frames, discontinuity count, optional callback-stage reason overlap, optional worker-stage loss, and optional source silence. A stage's `None` means **not observable**, not zero. Both direction records are independent cumulative **queue-local snapshots** and may be unavailable; other existing retained diagnostics still apply after close. Generation is a queue incarnation/reset marker, not USB protocol generation, wall-clock time, or cross-device identity.

For a **settled single queue** (no concurrent producer/consumer), `produced_frames = consumed_frames + dropped_at_ingress_frames + dropped_on_flush_frames + queued_frames + dropped_on_close_frames`; an unaccepted retryable suffix is external to `produced_frames`. This identity **does not** include synthetic output silence, because source demand has a separate clock: for a **finite graph callback fixture** with `N` requested output media positions, the receipt instead asserts `N = delivered_markers + rejected_markers + inserted_silence`. Do **not** add `inserted_silence` to an already complete queue input equation. Neither equation establishes where a host graph or USB client ultimately rendered the samples. No stage gets invented zero values just to balance an equation.

Per-direction `silence_inserted_frames` uses the actual source callback's own counter; the preexisting `underrun_frames()` remains the aggregate for compatibility. Real USB Samples mode exposes no independently maintained per-direction host-capture silence counter on the retained nonblocking diagnostics path, so the typed field is `None` there; the existing explicitly queried `AudioUsbMicrophoneProgress` remains authoritative for that worker-stage number.\n\nThe observable `dropped_in_callback_frames` is a *subset* of queue ingress discards when callback rejection is known. `dropped_in_worker_frames` is currently `None` because bridging this number into the root requires worker-control/IPC changes prohibited by this task. Existing worker diagnostics may be queried separately. The typed root record intentionally does **not** promise end-to-end lossless physical delivery. The experimental graph loss trace is capped; omitted events must not be treated as zero loss.

## Deterministic fake-clock receipt

`crates/gr-audio-contract/tests/fake_clock_receipt.rs` drives actual bounded queues with an injected monotonic fake clock and increasing positive per-frame markers. It checks exact queue conservation and per-callback demand conservation without PipeWire, VHCI, a real host or physical controller. Cases cover short admission and deliberate nonretryable overrun; underrun and zero padding (silence not mistaken for a captured marker); producer flush/reset with generation and discontinuity; consumer flush and terminal close with retained observer and idempotent terminal tail; duplicate, zero and out-of-order marker rejection. This is a **local SPSC/callback model**, not a production end-to-end marker capture. No tests or assertions were weakened.
