# ADR-0015 — Separate native-control admission and target exposure

Accepted for representation after
[EXP-0021](../experiments/EXP-0021-control-exposure.md); full evidence Gate T remains blocked.

Controller-native typed state may preserve independently evidenced controls even
when a target cannot expose them. Target-specific missing presentation belongs in
immutable surfaces/restrictions with its technical reason. Consumer mapping is
separate from both native identity and Linux presentation.

A firmware remap or macro description alone does not admit a new independent
semantic control. Record unknown raw visibility as unknown, not false. Current
corpus scoped claims/source classes express these facts without a schema change.
No Edge, Switch 2 or Pro 2 production package or support promotion is implied.
