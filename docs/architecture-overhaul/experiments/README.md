# Experiment records

Executed experiments and remaining prerequisites are indexed in the
[gate ledger](../GATE_STATUS.md). Records distinguish deterministic, live Linux,
and consumer evidence; they do not imply broader hardware equivalence.

Create run records here from [the EXP template](../templates/EXPERIMENT.md), using `EXP-B-001-<short-description>.md` style names. Allocate sequence numbers without overwriting earlier runs. Link records from [the status ledger](../GATE_STATUS.md), and link resulting ADRs from the run.

Keep corpus physical research in the corpus evidence tree once available; reference those records and the pinned commit here instead of duplicating their contents. Only sanitized summaries/manifests belong in this directory. The presence of a record or artifact does not constitute signoff.
