# Controller-native validation plan

The normative test requirements are maintained in
[CONTROLLER_NATIVE_API_SPEC.md](../implementation/CONTROLLER_NATIVE_API_SPEC.md)
and summarized in
[TESTING_TOOLING_SPEC.md](../implementation/TESTING_TOOLING_SPEC.md).

Support is claimed only when the controller's compiled realization and report
code pass hermetic contract tests plus the relevant prepared-host Linux gate.
Planner/profile/YAML tests from the previous architecture do not establish a
controller-native support claim.
